## 🎯 Purpose & Target Audience
**DSA MASTER AI** is purpose-built for engineering undergraduates studying Data Structures & Algorithms using **C Programming**. It provides tailored preparation for:
1. **Semester Theory Exams** (Autonomous colleges, Anna Univ, SRM, VTU, JNTU, KTU)
2. **Internal Assessments / Mid-Terms**
3. **Lab Practical Exams** (15 complete laboratory experiments)
4. **Lab Viva Voce** (Strict AI external examiner simulation)
5. **Technical Placements** (FAANG, TCS Digital, Zoho, Infosys SP, LeetCode patterns)
6. **Last Minute Revision** (15-min blitz, 30-min power, 1-hour comprehensive guides)

## 🌟 10 Core Features

### 1. 🤖 AI DSA Tutor (13-Part Structured Standard)
Every question is answered using the strictly enforced 13-part academic structure:
1. Simple Explanation
2. Detailed Explanation
3. Real-Life Analogy
4. ASCII / Structured Diagram
5. Step-by-Step Dry Run Table
6. Complete Compilable C Program
7. Time Complexity (Best, Average, Worst with mathematical derivation)
8. Space Complexity (Auxiliary vs Input breakdown)
9. Common Viva Questions with Examiner-approved answers
10. Common Mistakes & C Pitfalls (dangling pointers, memory leaks, off-by-one errors)
11. Semester Theory Exam Perspective (Mark distribution & key phrases to underline)
12. Lab Exam Perspective (Compiler nuances, input bounds, null checks)
13. Placement Perspective (LeetCode mappings, Two-Pointer / Sliding Window patterns)

### 2. 📚 Syllabus Tracker (5 Full Units)
Interactive checklist tracking completion, awarding **+50 XP** per topic and unlocking milestone badges:
- **Unit 1**: Structures, Self-Referential Structures, Pointers & Structures, Dynamic Memory Allocation (malloc, calloc, realloc, free), Matrix Multiplication, Big O, Omega, Theta, Time & Space Complexity.
- **Unit 2**: List ADT, Array Implementation, Cursor Implementation, Linked List, Doubly Linked List, Circular Linked List, Sparse Matrix, Polynomial Arithmetic, Josephus Problem.
- **Unit 3**: Stack, Queue, Circular Queue, Deque, Priority Queue, Infix to Postfix, Postfix Evaluation, Balancing Symbols, Tower of Hanoi, Scheduling.
- **Unit 4**: Trees, Tree Traversals (Inorder, Preorder, Postorder), Complete Binary Tree, BST, AVL Trees, Rotations (LL, RR, LR, RL), Heaps, Hashing, Separate Chaining, Open Addressing, Linear Probing, Quadratic Probing.
- **Unit 5**: Graph, BFS, DFS, Topological Sort (Kahn's), Prim's Algorithm, Kruskal's Algorithm, Dijkstra's Algorithm.

### 3. 🧪 Lab Exam Preparation Database (15 Experiments)
Complete syllabus repository for all 15 experiments:
1. Structures
2. Structures using Pointers
3. Matrix Multiplication using Dynamic Memory Allocation
4. Array Implementation of List
5. Linked List (Singly)
6. Doubly Linked List
7. Stack using Array and Linked List
8. Queue using Array and Linked List
9. Applications of Stack and Queue (Infix to Postfix & Evaluation)
10. Tree using Array
11. Binary Search Tree using Linked List
12. Graph Traversal using BFS
13. Graph Traversal using DFS
14. Dijkstra Shortest Path
15. Minimum Spanning Tree (Prim's Algorithm)

*Each experiment includes: Aim, Algorithm, C Program (with 1-click copy & syntax line numbers), Sample Input, Sample Output, Dry Run, Viva Questions, Common Errors, Memory Diagram, Complexity Analysis.*

### 4. ⏱️ Lab Exam Simulator
- Generates timed practical exams (e.g. *"Implement Queue using Linked List in C"*, 45 Minutes, 10 Marks).
- In-browser code editor with template boilerplate.
- Instant AI evaluation on:
  - **Logic & Correctness** (0-3 marks)
  - **Validation & Edge Cases** (0-2 marks)
  - **Output Formatting** (0-2 marks)
  - **Readability & Memory Safety** (0-1 mark)
  - **Viva Readiness** (0-2 marks)
- Automatically checks for bugs (missing `free()`, null pointer dereferences) and generates follow-up viva questions based directly on the student's written code!

### 5. 🎙️ Viva Trainer (Prof. Ramanathan External Examiner)
- Strict external examiner persona with realistic academic feedback.
- Select from 12 topics: Structures, Linked List, DLL, Stack, Queue, Tree, BST, BFS, DFS, Dijkstra, MST, Hashing.
- Adaptive difficulty (**Easy -> Medium -> Hard**).
- Real-time score tracker (0 to 100) with score deltas and hints.

### 6. 🔍 C Code Analyzer & Auditor
Paste any C code snippet to generate:
- Line-by-line explanation
- Bug & memory leak detector
- Improved C code with clean memory management
- Flowchart steps & algorithmic pseudocode
- Targeted viva questions
- Time and space complexity

### 7. 👁️ Interactive Algorithm Visualizers
Step-by-step animated visualizer with **Step Forward, Step Backward, Auto Play, and Speed Control (300ms - 2000ms)**:
- **Linked Lists**: Singly, Doubly, Circular (Insert Head/Tail, Delete Head/Tail, Animated Search)
- **Stack & Queue**: LIFO tower, FIFO pipe, Overflow, Underflow, Modulo arithmetic
- **Binary Search Tree**: Insert, Key search pathing, Inorder (sorted tape), Preorder, Postorder
- **Graphs**: BFS queue level highlight, DFS stack depth traversal, Dijkstra distance relaxations, Prim's MST edge selection

### 8. ⚡ Last Minute Revision
- Modes: **15 Minutes Blitz**, **30 Minutes Power**, **1 Hour Comprehensive**.
- High-yield formulas, essential algorithm steps, representative C snippets with exam tricks, and viva trap questions.

### 9. ❓ Smart Question Bank
- Filter by Unit (1 to 5), Difficulty (Easy, Medium, Hard), and Type.
- Interactive MCQ Quiz Mode with instant answer validation, explanations, and **+25 XP**.
- Descriptive 2-Mark, 5-Mark, and 10-Mark questions with model solutions.

### 10. 💼 Placement Mode
- Transforms university C DSA into FAANG / Product / MNC coding questions.
- Teaches pattern recognition: Two Pointers (Tortoise & Hare), Monotonic Stack, Sliding Window, Tree Traversals, Matrix Flood Fill, Topological Sort.
- LeetCode problem mappings with C implementation hints.

## 🚀 Quick Start Guide

### 1. Prerequisites
- Node.js (v18+)
- npm (v9+)

### 2. Configure Environment (.env)
Create or check `.env` in the root directory:
```env
PORT=5000
GEMINI_API_KEY=your_gemini_api_key_from_google_ai_studio
```

### 3. Run Development Servers
```bash
# Terminal 1: Backend API (Port 5000)
npm run dev:backend

# Terminal 2: Frontend App (Port 3000)
npm run dev:frontend
```
Open [http://localhost:3000](http://localhost:3000) in your browser!

### 4. Build for Production
```bash
npm run build:frontend
```
